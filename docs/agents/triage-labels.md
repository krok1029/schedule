# Triage Labels

| 技能角色 | 此 repo 標籤 | 意義 |
|---|---|---|
| needs-triage | needs-triage | 尚需評估需求 |
| needs-info | needs-info | 等待必要資訊 |
| ready-for-agent | ready-for-agent | 規格具體，適合 agent 處理 |
| ready-for-human | ready-for-human | 需要人工處理 |
| wontfix | wontfix | 決定不處理 |

ready-for-agent 不代表依賴已完成，也不授權無人值守、付費或跳過預算檢查。技能可將此標籤加在完整 spec／ticket 上；執行器仍須辨識父 spec 與 ticket，僅選可執行且依賴已通過的票。
